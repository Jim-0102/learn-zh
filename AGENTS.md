# Project Rules

## Repository Governance

- Treat `3dw/learn-zh` as the upstream public-interest project for the Association for Self-directed Learning Promotion. Do not push Jim's personal-version changes, early-intervention classroom branding, or extra personal promotion links back to the upstream project.
- Keep work for "學齡前的早療教室" and Jim's personal experiments in Jim's fork (`Jim-0102/learn-zh`) and deploy from that fork.
- Before pushing or opening a PR, verify the remote target. Use `git remote -v` and confirm whether the change belongs in `Jim-0102/learn-zh` or `3dw/learn-zh`.
- Upstream-facing changes must satisfy all three constraints from 3dw issue #16: public-interest use, public/open availability, and no additional personal promotion links except association promotion links.
