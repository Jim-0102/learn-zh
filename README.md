# 學齡前的早療小教室

## 這個專案是為誰設計的？

學齡前的早療小教室 是一個開放、免費的華文自學平台，讓任何人都能隨時隨地透過聆聽、跟讀與 AI 輔助，輕鬆學習華文。

### 真實使用情境

語言學習不應受限於時間與地點。我們相信，只要有好的工具與足夠的練習，每個人都能掌握台灣華文的基礎。

經歷過才知道身障兒家長的辛苦。祝福每一個遲緩的孩子，都有足夠的支持。

### 目前提供的功能

- **AI 圖片學** — 拍下身邊的任何物品，AI 立刻告訴你華文怎麼說。生活即教室，隨時隨地都能學華文。
- **情境識別互動題** — 依據圖片與對話判斷情境，分級題型可持續擴充題庫與圖片。
- **捷運站名測驗** — 聽站名、猜路線，用台北捷運練習華文地名發音。連續答對還有獎勵！
- **自訂朗讀** — 輸入任何華文文字，立即聆聽標準發音。反覆練習、聽說並進，讓口語越來越自然。
- **萌典** — 查詢華文單字、成語、詞組的釋義與用法。
- **站名學習** — 搭配路線圖與語音，認識台北捷運各站華文站名。以選擇題練習，輕鬆建立生活用字庫。
- **華文字卡（Flashcards）** — 用圖片搭配華文句子學習，支援台灣口音華文朗讀。可快速切換身體、情緒、在家情境與數字主題。
- **兌幣練習** — 拖拉硬幣到兌換區，練習硬幣面額換算，培養日常生活的數感與金錢概念。

### 未來發展方向

- 讓小孩看到圖片，可以正確解讀（例如：這個人在生氣）
- 讓小孩可以進一步理解圖片內容（例如：這兩個人很開心的在公園打球）
- 讓小孩可以正確對答（例如：在別人讚美你的時候，要回答謝謝）

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.
